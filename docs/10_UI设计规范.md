# 10 UI 设计规范（2026-10-07 森林系基线）

> 本文档记录当前已合并到小程序工作区的视觉规范。后续前端 AI 只调整视觉与组件实现，不改变既有操作逻辑和字段。

## 1. 设计定位
- 年轻、温暖、有陪伴感，面向 Z 世代与学生用户。
- 关键词：森林系、描边卡片、轻 3D、贴纸感、企鹅 IP、不过度金融化。
- 视觉代码基线：`miniprogram/app.wxss` 中的 CSS 变量。

## 3. 描边与阴影
- 描边宽度：3rpx。
- 卡片圆角：32rpx；小按钮/输入框：999rpx；中组件：24rpx。
- 卡片阴影：0 6rpx 0 rgba(10,51,35,0.10)。
- 浮层阴影：0 10rpx 0 rgba(10,51,35,0.16)。
- 按钮按下通过 `.tap` 统一缩放，或使用向下位移 + 阴影收短。

## 4. 字体与数字
- 字号梯度：20/22/24/26/28/32/40/60rpx。
- 正文 400，标题 600~700，按钮 700。
- 金额使用 `font-variant-numeric: tabular-nums`，金额前缀独立为小号 ¥。
- 中文优先 PingFang SC / Microsoft YaHei，系统字体兜底。

## 5. 心情标签
固定五档：很开心、开心、平静、心情一般、难过；每档支持自定义标签。
| 档位 | 主色 |
|---|---|
| 很开心 | #D3968C |
| 开心 | #839958 |
| 平静 | #105666 |
| 心情一般 | #F7F4D5 |
| 难过 | #0A3323 |
- 两行三列；第五个固定标签后接“＋ 自定义”。
- 只有选中态使用对应色浅底和描边，未选中保持低对比。

## 6. 组件规范
- 卡片：白底 + #0A3323 描边 + 32rpx 圆角 + 硬阴影，不使用蓝紫色渐变。
- 自定义 tabBar：5 个入口；选中态为暖粉圆底 + 深绿描边；图标使用 `icons.wxss` 线性 SVG。
- 主按钮：草绿底、白字、描边、硬阴影；按下向下 6~8rpx。
- 输入框：奶油底、深绿描边、全圆角。
- 企鹅 IP：使用 `components/mascot-penguin`；默认右下角悬浮，可拖动到安全位置，可点击 × 隐藏；“显示企鹅”按钮可一键召回。隐藏、位置和召回状态通过 App 全局状态广播，在所有页面实时一致并持久化。
- 装饰插画：首页使用 reading/cake/cycling/walking，位于内容底层，不遮挡可点击区域。

## 7. 页面实现映射
- 全局变量与组件：`miniprogram/app.wxss`
- 图标：`miniprogram/icons.wxss`
- 自定义导航：`miniprogram/custom-tab-bar/`
- 企鹅组件：`miniprogram/components/mascot-penguin/`（头部与左翅膀已于 2026-10-08 替换为美工新稿）
- 企鹅预览：`miniprogram/pages/penguin-preview/`
- 首页：`pages/index/`
- 账单：`pages/bill/`
- 记一笔：`pages/chat/`
- 订阅：`pages/subscription/`
- 我的：`pages/profile/`

## 8. 必须保留的操作逻辑
- 底部五个入口：首页/账单/记一笔/订阅/我的。
- 首页：今日收支、提醒、早/中/晚心情 + 自定义、记一笔、今日日记。
- 聊天页：输入、发送、语音/拍照入口、消息左右分栏、自动滚动与回到底部。
- 订阅/预算等提醒只展示内容，不改变原有数据字段和云函数调用协议。
- 不把“开发中”占位误当作已实现功能；接数据时替换文案和事件逻辑。

## 9. 验收重点
- 全部页面使用统一色板、描边和阴影，不残留旧蓝色渐变样式。
- 320~430px 常见宽度下无溢出、遮挡和文字截断。
- 自定义 tabBar 在安全区与输入栏场景下不遮挡内容。
- 真机检查图片清晰度、点击区域、动画性能和深色系统环境兼容性。
