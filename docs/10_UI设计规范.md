# 10 UI 设计规范（给前端 AI 的操作规范）

> 使用说明：前端 AI 拿到本规范后，只能改"视觉"（颜色、字体、圆角、图形、装饰），不能改"操作逻辑"（页面结构、交互流程、字段、按钮功能）。逻辑以骨架代码和 PRD 为准。

## 1. 设计定位
年轻、清新、有温度，面向 Z 世代 / 大学生。关键词：轻盈、友好、不冰冷。

## 2. 色彩系统
| 用途 | 色值 | 说明 |
|---|---|---|
| 主色 primary | #3a7afe | 按钮、选中态、强调 |
| 主色浅 primary-light | #eaf0ff | 选中背景、浅色块 |
| 成功 | #22c55e | 收入、完成 |
| 警告 | #f59e0b | 预算超支、提醒 |
| 危险 | #ef4444 | 超支、取消、错误 |
| 文字主 | #1f2329 | 标题、正文 |
| 文字次 | #6b7280 | 辅助说明 |
| 文字浅 | #9aa0a6 | 占位、次要 |
| 页面背景 | #f7f8fa | 全局底 |
| 卡片 | #ffffff | 卡片底 |
| 分割线 | #f2f3f5 | 列表分隔 |

## 3. 心情标签配色（特色，必须统一）
| 心情 | 色值 | 情感 |
|---|---|---|
| 很开心 | #f97316 | 暖橙、活力 |
| 开心 | #fbbf24 | 明黄、轻快 |
| 平静 | #14b8a6 | 青绿、安宁 |
| 心情一般 | #94a3b8 | 灰蓝、平淡 |
| 难过 | #6366f1 | 靛蓝、低落 |
| 自定义标签 | 默认 #eaf0ff / 文字 #3a7afe | 中性 |

## 4. 字体
- 字号梯度：22rpx(辅助) / 24rpx(标签) / 26rpx(次要) / 28rpx(正文) / 32rpx(标题) / 40rpx(大数字) / 56rpx(金额)
- 字重：正文 400，标题 600，金额 700
- 数字用等宽感（可用 font-feature-settings: "tnum"）

## 5. 间距与圆角
- 页面边距：24rpx；卡片内边距：24rpx
- 卡片圆角：16rpx；按钮/标签圆角：全圆(48rpx/36rpx)
- 阴影：0 2rpx 12rpx rgba(31,35,41,0.04)

## 6. 组件规范
- 卡片：白底 + 16rpx 圆角 + 轻阴影，上下间距 16rpx，左右 24rpx
- 主按钮：主色底、白字、全圆角、按压 opacity 0.85
- 输入框：浅灰 #f2f3f5 底、全圆角、无边框
- 标签：浅色底、圆角 28rpx、字号 24rpx；选中态用 primary-light 底 + primary 字
- 心情标签：选中态用对应心情色浅底 + 深字（见上表）

## 7. 图标与图形
- 优先 emoji 占位（🎤📷📖🔍），正式版再换统一线性图标
- 图形风格：圆润、线性、避免写实

## 8. 必须保留的操作逻辑（前端 AI 不可改动）
- 底部 tab 五个：首页/账单/记一笔/订阅/我的
- 首页心情选择：早/中/晚三个时段，每时段可选 5 种心情 + 自定义
- 聊天页：底部输入框 + 语音/拍照按钮 + 发送，消息气泡左右分栏
- 所有"开发中"的 TODO 占位，等后端接数据后替换
