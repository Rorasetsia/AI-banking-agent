# 11 数据模型（给后端 AI 的建库规范）

> 使用说明：后端 AI 按本文档在微信云开发-云数据库创建集合，并据此编写云函数。字段名一律英文小写驼峰，日期用 ISO 字符串或时间戳。所有集合自动带 _id 和 _openid（云开发自动）。

## 1. users 用户与偏好
| 字段 | 类型 | 说明 |
|---|---|---|
| nickname | string | 昵称 |
| avatar | string | 头像 URL |
| categoryPrefs | object | 分类偏好，如 { "瑞幸": "咖啡" } |
| payAccounts | array | 常用账户 id 列表 |
| moodCustomTags | array | 自定义心情标签 |
| assistantContext | object | 持久化对话上下文：history、lastAction、recentActions、pendingAction、preferenceRules |

## 2. accounts 账户/支付方式
| 字段 | 类型 | 说明 |
|---|---|---|
| name | string | 如"微信零钱"、"招行卡" |
| type | string | wallet/card/other |
| icon | string | 图标或 emoji |

## 3. transactions 流水（核心）
| 字段 | 类型 | 说明 |
|---|---|---|
| amount | number | 金额，支出为负、收入为正 |
| category | string | 分类：餐饮/交通/购物/娱乐/居住/医疗/教育/其他 |
| accountId | string | 关联账户 |
| merchant | string | 商户，如"喜茶"、"八合里" |
| itemName | string | 具体消费内容，如"波波奶茶"、"聚餐" |
| remark | string | 简短备注（如"晨光酸奶"） |
| rawText | string | 用户原话或 AI 原始识别文本 |
| tags | array | 回忆标签，如"和朋友"、"生日" |
| people | array | 同行人/参与者，如"女朋友"、"朋友" |
| relationship | string | 关系，如女朋友/朋友/同事 |
| socialAction | string | 社交行为，如请客/聚餐/AA/约会 |
| occasion | string | 场合，如生日/纪念日 |
| aaPeople | number | AA 人数，仅 AA 场景使用 |
| memo | string | 可编辑的长备注或回忆说明 |
| date | string | ISO 日期 YYYY-MM-DD |
| time | string | HH:mm |
| source | string | manual/chat/photo/voice |
| timezone | string | 默认 Asia/Shanghai |
| ledgerId | string | 关联共同账本（可选） |
| merchant | string | 商家（拍照识别时） |
| updatedAt | date | 最近修改时间 |

## 8.55 学习规则 preferenceRules

`users.assistantContext.preferenceRules` 保存用户学习到的默认规则：

- field：ledger/category/merchant 等
- value：具体默认值
- matchKeywords：触发关键词
- excludeKeywords：例外关键词
- sourceText：学习来源

示例：

```json
{"field":"ledger","value":"shared","matchKeywords":["女朋友","吃饭"],"excludeKeywords":["我请"]}
```

## 8.6 统一账本服务

前端账单页、订阅页和 AI 共用 `ledgerService`（或同一字段规范），操作包括交易增删改查、订阅增删改查/取消、共同账本创建/加入/列表。

## 9. 建库顺序建议
users -> accounts -> transactions -> subscriptions -> budgets -> goals -> moods -> diaries -> reminders
