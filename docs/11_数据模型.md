# 11 数据模型（给后端 AI 的建库规范）

> 使用说明：后端 AI 按本文档在微信云开发-云数据库创建集合，并据此编写云函数。字段名一律英文小写驼峰，日期用 ISO 字符串或时间戳。所有集合自动带 _id 和 _openid（云开发自动）。

## 1. users 用户与偏好
| 字段 | 类型 | 说明 |
|---|---|---|
| nickname | string | 昵称 |
| avatar | string | 头像 URL |
| categoryPrefs | object | 分类偏好，如 { "瑞幸": "咖啡" } |
| payAccounts | array | 常用账户 id 列表 |
| moodCustomTags | array | 自定义心情标签 |

## 2. accounts 账户/支付方式
| 字段 | 类型 | 说明 |
|---|---|---|
| name | string | 如"微信零钱"、"招行卡" |
| type | string | wallet/card/other |
| icon | string | 图标或 emoji |

## 3. transactions 流水（核心）
| 字段 | 类型 | 说明 |
|---|---|---|
| amount | number | 金额，支出为负、收入为正 |
| category | string | 分类：餐饮/交通/购物/娱乐/居住/医疗/教育/其他 |
| accountId | string | 关联账户 |
| remark | string | 备注（如"晨光酸奶"） |
| date | string | ISO 日期 YYYY-MM-DD |
| time | string | HH:mm |
| source | string | manual/chat/photo/voice |
| ledgerId | string | 关联共同账本（可选） |
| merchant | string | 商家（拍照识别时） |

## 4. subscriptions 订阅
| 字段 | 类型 | 说明 |
|---|---|---|
| name | string | 如"腾讯视频VIP" |
| amount | number | 每期金额 |
| cycle | string | monthly/yearly/weekly |
| nextDate | string | 下次扣费日期 |
| status | string | active/cancelled |
| autoRenew | boolean | 是否自动续费 |

## 5. budgets 预算
| 字段 | 类型 | 说明 |
|---|---|---|
| category | string | 预算分类 |
| amount | number | 额度 |
| period | string | monthly/yearly |

## 6. goals 攒钱目标
| 字段 | 类型 | 说明 |
|---|---|---|
| name | string | 目标名 |
| targetAmount | number | 目标金额 |
| savedAmount | number | 已存 |
| deadline | string | 截止日期 |

## 7. moods 心情
| 字段 | 类型 | 说明 |
|---|---|---|
| date | string | YYYY-MM-DD |
| period | string | morning/noon/night |
| mood | string | 很开心/开心/平静/心情一般/难过 |
| customTag | string | 自定义标签（可选） |

## 8. diaries 每日日记
| 字段 | 类型 | 说明 |
|---|---|---|
| date | string | YYYY-MM-DD |
| content | string | 日记正文（AI 生成） |
| moodSummary | string | 当天心情摘要 |
| expenseSummary | string | 当天账目摘要 |

## 8.4 ledgers 共同账本
| 字段 | 类型 | 说明 |
|---|---|---|
| inviteCode | string | 邀请码（6位） |
| name | string | 账本名 |
| members | array | 成员 openid 列表（最多2人） |

## 8.5 reminders 提醒
| 字段 | 类型 | 说明 |
|---|---|---|
| type | string | subscription / budget |
| content | string | 提醒文案 |
| read | boolean | 是否已读 |
| date | string | 生成日期 |

## 9. 建库顺序建议
users -> accounts -> transactions -> subscriptions -> budgets -> goals -> moods -> diaries -> reminders
