# 07 协作规范（多 Agent / 多设备）

## 1. 单一事实源
- docs/00_项目记忆.md 是唯一权威状态源。
- 任何 Agent / 成员：开工前先读它，收工后立即更新"当前状态/下一步"。
- 冲突时以本文件为准。

## 2. 状态枚举（统一用词）
TODO（未开始）→ DOING（进行中）→ DONE（完成）→ BLOCKED（阻塞，注明原因）

## 3. 每日复盘模板（daily/YYYY-MM-DD.md）
```
# YYYY-MM-DD 复盘
## 已完成
## 卡点 / 阻塞
## 明日计划
## 花费与 Token
## 需要他人/用户配合的事
```

## 4. 多设备同步（已确定：GitHub）
- 远端：https://github.com/Rorasetsia/AI-banking-agent.git
- 每台设备开工：git pull；收工：git add -A && git commit && git push
- 若遇冲突，以 00_项目记忆.md 的"当前状态"为准，手动合并

## 5. 给 Agent 的开工/收工协议
- 开工：读 00_项目记忆.md → 读对应 docs/0X → 读 tasks/TASKS.machine.md 领取任务 → 状态改 DOING
- 收工：更新任务状态 → 写 daily/ 复盘 → 更新 00_项目记忆.md 的"当前状态/下一步" → git commit + push

## 6. 分工约定
- 两人全程一起完成（不拆前后端），任务负责人字段统一用 ALL 表示两人共同
