# 07 协作规范（多 Agent / 多设备）

## 1. 单一事实源
- docs/00_项目记忆.md 是唯一权威状态源。
- 任何 Agent / 成员：开工前先读它，收工后立即更新"当前状态/下一步"。
- 冲突时以本文件为准。

## 2. 最小阅读集（提升效率，别全读）
- 每次开工只读：00_项目记忆.md + tasks/TASKS.machine.md
- 其余文档按 README 的"何时读"列按需取用，不读无关文档
- 文档分级：P0 必读 / P1 按需 / P2 参考，见 README

## 3. 状态枚举（统一用词）
TODO（未开始）-> DOING（进行中）-> DONE（完成）-> BLOCKED（阻塞，注明原因）

## 4. 每日复盘模板（daily/YYYY-MM-DD.md）
# YYYY-MM-DD 复盘
## 已完成
## 卡点 / 阻塞
## 明日计划
## 花费与 Token
## 需要他人/用户配合的事

## 5. 多设备同步（GitHub）
- 远端：https://github.com/Rorasetsia/AI-banking-agent.git
- 每台设备开工：git pull；收工：git add -A && git commit && git push
- 若遇冲突，以 00_项目记忆.md 的"当前状态"为准，手动合并

## 6. 给 Agent 的开工/收工协议
- 开工：读 00 与任务清单 -> 领任务改 DOING -> 读该任务涉及的"按需"文档
- 收工：更新任务状态 -> 写 daily 复盘 -> 更新 00 的"当前状态/下一步" -> git commit + push

## 7. 分工约定
- 两人全程一起完成（不拆前后端），任务负责人字段用 ALL 表示两人共同
