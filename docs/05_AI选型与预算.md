## 3. Flash vs Pro 预算估值对比（开发期全周期）

### 估算假设（中性档）
- 基线消耗（Pro 一次成型）：输入 2000 万 tokens，输出 600 万 tokens
- Flash 因代码 bug 更多，总消耗上浮 40%（多轮修 bug）：输入 2800 万、输出 840 万
- 时段分布：高峰 60% / 空闲 40%（白天写代码为主）
- 缓存命中率：30%（多轮对话、调试回读触发缓存）

### 计算结果
| 项目 | Flash | Pro |
|---|---|---|
| 有效输入(未命中) | 2800万×70%=1960万 | 2000万×70%=1400万 |
| 输入(缓存命中) | 840万 | 600万 |
| 输出 | 840万 | 600万 |
| 输入未命中成本 | 1960万×2.4元/百万≈47.0元 | 1400万×7.2元/百万≈100.8元 |
| 输入命中成本 | 840万×0.08元/百万≈0.7元 | 600万×0.24元/百万≈1.4元 |
| 输出成本 | 840万×7.2元/百万≈60.5元 | 600万×21.6元/百万≈129.6元 |
| **合计** | **≈ 108 元** | **≈ 232 元** |

> 说明：输入未命中均价 Flash=0.6×3.0+0.4×1.5=2.4元；Pro=0.6×9.0+0.4×4.5=7.2元；输出均价 Flash=7.2元、Pro=21.6元。

### 结论与建议
- 纯 Flash ≈ 108 元，纯 Pro ≈ 232 元，**差额约 124 元**。
- 但 Flash 质量低、返工多，**时间成本约 +40%**（两人各多花约 20~30 小时），而时间也是成本。
- **最优：混合策略**——日常代码/前端走 Trae 积分（免费）或 Flash；关键架构设计、Agent 编排、疑难 bug 走 Pro。预期现金成本可压在 **100 元以内**。
- 运行时 Agent 对话走混元免费额度（1 亿 token），接近 0 成本。
- 若需节流：把大段代码生成安排在 23:00~9:00 空闲时段（Flash 未命中仅 1.5 元、Pro 仅 4.5 元），成本可再降约一半。

## 2026-10-10 资源点与外部服务核对

当前 CloudBase 个人版：19.9 元/月，40000 资源点/月，1000 点约等于 1 元资源价值。

CloudBase 资源点会覆盖：
- 云函数调用：13.3 点/万次
- 云函数资源使用量：0.11108 点/GBs
- 文档数据库调用：200 点/万次
- 云存储读写：10 点/万次
- CloudBase AI 调用与内置模型 Token

腾讯云 OCR 与语音识别 ASR 不属于 CloudBase 40000 资源点，单独计费：
- 一句话识别示例：3 万次约 90 元，10 万次约 120 元；有独立免费额度，具体以控制台为准。
- OCR 按页/次/票据种类计费，资源包低档从几十元起。

决策：照片 OCR 和语音 ASR 暂时搁置，不纳入当前小程序主线。
