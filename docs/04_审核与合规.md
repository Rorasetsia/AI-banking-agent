# 04 审核与合规（小程序上线生死线）

## 1. 核心原则
- **定位必须是"记账/工具/生活服务"，绝不出现"银行、理财购买、转账到真实账户、信用卡额度、贷款"等真实金融业务字眼**
- 微信对"金融业"类目（银行/理财/基金/证券）要求上传《金融许可证》《经营证券期货业务许可证》等，个人主体无法提供

## 2. 类目选择建议
- 首选：**工具 > 效率 / 生活服务**（个人可开通）
- 备案：小程序需完成 ICP 备案（个人可备，选"生活服务/工具"类服务内容）

## 3. 功能表述的"安全措辞"（红线）
| 想表达 | 禁止出现 | 安全措辞 |
|---|---|---|
| 记账转账 | 转账、汇款、支付 | "记一笔支出/收入"、"AA 分账" |
| 订阅管理 | 代扣、自动扣费取消 | "订阅提醒"、"订阅整理" |
| 理财 | 申购、赎回、基金、收益 | "攒钱目标"、"预算规划" |
| 卡片 | 信用卡、额度、挂失 | "支付方式"、"账户" |

## 4. 数据与隐私
- 用 mock 数据演示，不接真实银行/支付 API
- 隐私政策页 + 用户协议页（上架必需）

## 5. 审核节奏提醒
- 小程序首次提审约 1-3 个工作日，**务必 10-07 前首次提审**，预留返工时间
- 涉及 AI 内容需在后台"AI 能力"板块说明用途（2026 微信要求）
