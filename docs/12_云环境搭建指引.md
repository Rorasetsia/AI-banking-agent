# 12 云开发环境搭建指引（用户手动操作，D1-01）

## 第 1 步：安装微信开发者工具
- 下载：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
- 安装后用微信扫码登录（需是注册小程序的那个微信号/管理员）

## 第 2 步：导入本项目
- 打开开发者工具 -> 导入项目 -> 选择目录：D:\sutdy\大二\竞赛\小程序 + 深圳金融科技大赛
- AppID 已写入 project.config.json（wxbdbdac4e591d951f），会自动带出

## 第 3 步：开通云开发
- 顶部工具栏点「云开发」按钮 -> 首次会提示开通 -> 选择「按量付费」或免费额度环境
- 创建一个环境，命名如 ai-caiguan
- 记下「环境 ID」（形如 ai-caiguan-xxxxx）

## 第 4 步：填入环境 ID
- 打开 miniprogram/app.js
- 把 env: 'YOUR_ENV_ID' 改成你的真实环境 ID
- 保存

## 第 5 步：开通 AI 能力（成长计划 + 混元）
- 云开发控制台 -> AI -> 生文模型 -> 勾选「混元 Hy3 / hunyuan」等
- 或在小程序后台 mp.weixin.qq.com -> 行业能力 -> AI 小程序成长计划 -> 提交申请（简介见 docs/08）

## 第 6 步：创建数据库集合
- 云开发控制台 -> 数据库 -> 新建集合，按 docs/11_数据模型.md 建 8 个：
  users / accounts / transactions / subscriptions / budgets / goals / moods / diaries
- 权限默认"仅创建者可读写"即可（个人账本）

## 完成标志
- 小程序预览能正常显示 5 个 tab
- 云开发控制台能看到 8 个集合
- 环境 ID 已填入 app.js
