# 02 产品定义（PRD）

## 1. 定位
- **小程序端**：AI 智能记账 / 财务管家（工具/生活服务类目，个人可过审）
- **网页端（FinTechathon）**：AI Banking Agent 全量演示（覆盖 6 场景，注明为演示）
- **暂定名**：AI财务管家（待用户确认）

## 2. 目标用户与场景
- 大学生 / Z 世代 / 情侣 / 合租室友：记账、管订阅、AA 分账、攒钱

## 3. 功能清单（场景映射）
| 官方场景 | 我们的落地 | 优先级 |
|---|---|---|
| 账单分析 | AI 自动分类记账、异常交易识别、月度/年度报告、自然语言问账 | 核心 |
| 订阅/代扣管理 | 自动识别订阅扣费、续费提醒、订阅体检报告、一键取消 | 核心 |
| 智能转账 | 对话式记账、定时记账、AA 分账、双人共同账本 | 核心 |
| 理财操作 | 攒钱目标、预算规划、智能储蓄建议（不碰真实申购赎回） | 轻量 |
| 卡片管理 | 多账户/多支付方式管理（标签化，不做真实额度/挂失） | 轻量 |
| 跨场景联动 | 预算超支/订阅到期/生日纪念日主动提醒 | 亮点 |

## 4. 创新点（4 抓手，建议 2 主 2 次）
1. **多模态记账**（主）：拍照小票 OCR + 语音记账自动入账
2. **对话式财务管家**（主）：NL→理解→规划→执行（AI 赛道核心考核）
3. **AI 主动性**（次）：订阅到期/预算超支/固定支出/生日主动提醒
4. **个性化记忆**（次）：用户纠正分类后 AI 学习偏好

## 5. 核心数据模型（初版）
- account 账户/支付方式
- transaction 流水（金额、时间、分类、账户、备注、来源）
- subscription 订阅（名称、周期、金额、下次扣费日、状态）
- budget 预算（分类、额度、周期）
- goal 攒钱目标
- user 用户 + 偏好记忆

## 6. 卖点（2 人团队可主打）
- **双人共同账本**（情侣/合租场景，契合 2 人团队演示）
- **订阅体检报告 + 一键整理**（Z 世代痛点）
