# 02 产品定义（PRD）

## 1. 定位
- 小程序名：AI财务管家
- 小程序端：AI 智能记账 / 财务管家（工具/生活服务类目，个人可过审）
- 网页端（FinTechathon）：AI Banking Agent 全量演示（覆盖 6 场景，注明为演示）

## 2. 目标用户与场景
- 大学生 / Z 世代 / 情侣 / 合租室友：记账、管订阅、AA 分账、攒钱、记录心情

## 3. 功能清单（场景映射）
| 官方场景 | 我们的落地 | 优先级 |
|---|---|---|
| 账单分析 | AI 自动分类记账、异常识别、月度/年度报告、自然语言问账 | 核心 |
| 订阅/代扣管理 | 自动识别订阅扣费、续费提醒、订阅体检报告、一键取消 | 核心 |
| 智能转账 | 对话式记账、定时记账、AA 分账、双人共同账本 | 核心 |
| 理财操作 | 攒钱目标、预算规划、智能储蓄建议（不碰真实申购赎回） | 轻量 |
| 卡片管理 | 多账户/多支付方式管理（标签化，不做真实额度/挂失） | 轻量 |
| 跨场景联动 | 预算超支/订阅到期/生日纪念日主动提醒 | 亮点 |

## 3.5 自有创新功能（超出官方场景）
| 功能 | 说明 | 优先级 |
|---|---|---|
| 多模态记账 | 图片(拍照小票)+语音+文字三种入账 | 主攻 |
| 每日心情日记 | 每天 AI 生成日记式总结，融合账目+心情 | 主攻亮点 |
| 心情选择 | 早/中/晚勾选心情 + 自定义标签 | 配套 |
| 情感×消费洞察 | 周/月报分析心情与消费的关联 | 增强 |

## 4. 创新点
详见 docs/09_创新点详解.md。主线：多模态记账 -> 对话式管家 -> 心情日记 -> 个性化记忆 -> 主动提醒。
- 主攻：对话式财务管家、多模态记账
- 体验亮点：每日心情日记（情感×消费洞察）
- 次要：AI 主动性提醒、个性化记忆

## 5. 核心数据模型（初版）
- account 账户/支付方式
- transaction 流水（金额、时间、分类、账户、备注、来源）
- subscription 订阅（名称、周期、金额、下次扣费日、状态）
- budget 预算（分类、额度、周期）
- goal 攒钱目标
- mood 心情（date、period 早/中/晚、mood 标签、customTag 自定义）
- diary 每日日记（date、内容、心情、账目摘要）
- user 用户 + 偏好记忆

## 6. 卖点
- 双人共同账本（情侣/合租场景，契合 2 人团队演示）
- 订阅体检报告 + 一键整理（Z 世代痛点）
- 每日心情日记 + 情感洞察（情绪陪伴，差异化杀手锏）
