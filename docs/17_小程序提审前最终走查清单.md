## B. 真机核心链路
### B1 文字记账与查询
1. 语音/文字输入：`午饭在喜茶花了28元`。
2. 进入账单页，确认当天出现该记录。
3. 发送：`查看本月明细`，确认返回明细列表。
4. 手动编辑标题、商户、备注和标签后保存。
5. 再次让 AI 查询，确认能读到人工补充字段。

### B2 补充与纠错
1. 发送：`午饭花了`，确认不会写库。
2. 发送：`30元`，确认只生成一笔记录。
3. 发送：`不是30，是35`，确认更新原记录。
4. 重启小程序，再发送纠错语句，确认上下文仍能恢复。

### B3 个人/共同账本
1. 创建共同账本。
2. 复制邀请码或分享给第二个微信账号。
3. 第二账号加入，确认成员关系。
4. 设置家庭/情侣/朋友关系。
5. 测试`买菜花了40元`和`我请女朋友吃饭花了52元`，确认归属区分。
6. 退出共同账本，二次确认后成功退出。

### B4 预算与攒钱目标
1. 设置日预算100元，确认月预算按月天数推算。
2. 设置月预算3100元，确认日预算反推为100元。
3. 新增分类预算，确认显示月/日额度。
4. 新建攒钱目标，编辑金额、已存金额和截止日期。
5. 连续检查预算提醒，确认同一预算只显示一条，已用金额随本月个人支出更新且不会把共同账本重复计入。
6. 在预算页切换到共同账本，分别设置总预算和分类预算，调整提醒阈值；确认另一成员能看到同一预算，双方支出汇总后只各收到一条提醒。
7. AI 分别测试个人/共同预算的“只改提醒阈值、不重新输入金额”，确认原预算金额不变，阈值正确更新。

### B5 订阅
1. AI/手动新增测试订阅。
2. 编辑金额、周期和下次扣费日期。
3. 点击续费，确认初次订阅日期不变。
4. 取消订阅，确认进入历史订阅。
5. 记录腾讯视频VIP/会员，确认相似订阅会反问。

### B6 心情与日记
1. 首页选择早上/下午/晚上心情，确认选项消失并显示反馈。
2. 新建一笔交易后进入日记，确认自动更新。
3. 编辑标题和正文，测试加粗、颜色、字号、撤销。
4. 点击 AI 润色，确认前后对比。
5. 导出 TXT/HTML；若文件分享失败，确认复制文本可用。
6. 重新进入日记，确认数据无变化时不重复生成。

### B7 聊天和 UI
1. 聊天列表滚到顶部，确认历史入口出现，可点击/下滑展开。
2. 展开历史后确认按钮隐藏且不遮挡聊天。
3. 打开键盘，确认输入栏紧贴键盘；切 tab 后键盘收起。
4. 首页切账单、订阅、我的，确认企鹅状态一致。
5. 检查空状态、加载状态、错误提示和按钮文字居中。
