# 09 创新点详解（思考点在哪、凭什么赢）

## 0. 一条主线：先讲清"我们到底创新了什么"
普通记账 App 的三大死穴：记起来麻烦、记了不会用、记着记着就放弃。
我们的创新不是"加了个 AI 聊天框"，而是用 AI 重构记账的整条链路，一句话概括：

> 从"懒得记" → 到"不用记"（多模态自动入账）→ 到"它会主动帮你想"（对话管家 + 主动提醒）→ 到"它会陪你"（每日心情日记）。

创新点是一条链：
多模态记账(降低输入摩擦) → 对话式管家(懂意图、会建议) → 心情日记(情绪陪伴+粘性) → 个性化记忆(越用越准) → 主动提醒(从工具变管家)

---

## 1. 对话式财务管家（主攻，AI 赛道核心考核点）
痛点：记账最大的敌人是"麻烦"。选分类、填金额、记备注，三步以上，用户坚持不了 7 天。
创新：把"填表记账"变成"说话办事"。用户说人话，Agent 理解意图 → 自主规划 → 执行。

具体场景：
- "午饭和同事吃了 45，AA 一下" → 自动记一笔 45 元餐饮 + 识别 AA 意图 + 拆成每人应付
- "这月我是不是花太多了？" → Agent 自主规划：查账单、分类统计、对比上月、发现餐饮超支、主动追问"要不要设个餐饮预算？"
- 信息不全主动追问："帮我还花呗" → "是还 500 那笔吗？几号还？"

技术：意图识别(NLU) → 槽位抽取(金额/分类/时间/对象) → function calling → 多轮上下文 → 主动追问/确认。
凭什么赢：普通 App 是"记录工具"，我们是"会算账、会建议的管家"，正是大赛"意图理解 + 规划 + 执行"三连。

---

## 2. 多模态记账（主攻：图片 + 语音 + 文字）
痛点：手动输入是摩擦最大的环节，尤其小票、发票、转账截图。
创新：三种输入方式全覆盖——
- 图片：拍照小票 → OCR → AI 自动拆解（商家/金额/日期/分类）
- 语音：说一句"打车花了 30"自动入账
- 文字：写一句"中午喝了晨光酸奶，花了 5 块钱" → AI 识别时间(中午)、品类(酸奶)、金额(5块)、分类(餐饮)自动入账

具体场景：聚餐拍一张小票 → 自动识别总额+明细 → 一键记账，直接接"AA 分账"。
技术：微信云开发 OCR / 混元多模态识别 + 语音识别，结果交 Agent 二次确认。
凭什么赢：别人拍照只是"存图"，我们做到"拍完/说完/写完自动入账 + 自动分类 + 能对话追问"。

---

## 3. 每日心情日记（体验亮点，差异化杀手锏）
痛点：用户想记录生活却坚持不下来；记账 App 打开率低。
创新：每天结尾 AI 生成一篇"日记式总结"，融合当天账目 + 当天心情，让账单变成有温度的生活记录。

心情输入设计（轻量）：
- 用户每天勾选早/中/晚心情：很开心 / 开心 / 平静 / 心情一般 / 难过，也可自定义标签
- 三选一即可，不必三个时段都填

日记示例（融合账目+心情，以用户一手信息为主）：
> 今天你花了 128 元：中午晨光酸奶 5 块、晚饭和朋友聚餐 95 块……你标记"今天很开心"，并备注"和朋友聚餐"。以上是你今天的账单小记。

情感×消费关联呈现（助手型，周报/月报）：
- 只摆事实："你本月标记了 6 天'难过'，这 6 天共支出 X 元，其中奶茶/外卖占 Y%。"
- 用假设口吻、可被纠正："数据显示那几天奶茶支出较多，你可以看看是不是这样。"
- 结论权交给用户，不替用户下判断。

边界原则（重要，防弄巧成拙）：
- 只做：陈述用户主动提供的心情标签；用客观消费数据做关联呈现；用"可能/看起来/数据显示"的假设口吻
- 不做：心理归因（"你难过是因为..."）；擅自追问私人问题；把假设当结论强加给用户
- 角色定位：AI 是"帮你整理、呈现、提醒"的助手，不是心理分析师；解读权和结论权始终在用户手里

技术：mood 集合存心情(date/period/mood/customTag) → 每日云函数拉当天 transaction+mood → 调混元生成日记 → 存 diary 集合 → 展示/订阅消息推送。
凭什么赢：别人是"记账工具"，我们是"情绪陪伴"，且始终以用户一手信息为准、不过度解读。

## 4. AI 主动性提醒（次：跨场景联动）
痛点：用户不会天天开 App；订阅扣费、预算超支总是事后发现。
创新：从"被动工具"变"主动管家"，预测并提醒，而非事后通知。

场景（对应大赛"跨场景联动"）：
- 订阅快到期 → 提前 3 天提醒"某视频会员明天续费 25 元，要取消吗？"
- 餐饮花 80% 预算 → 提前预警"按这速度月底会超支 200"
- 固定支出变化（房租涨了）→ 主动提醒
- 生日/纪念日 → 联动提醒（呼应大赛示例）

技术：云函数定时触发器扫描订阅/预算数据 → 生成提醒 → 订阅消息推送。

---

## 5. 个性化记忆（次）
痛点：通用分类不准（"瑞幸"算餐饮还是咖啡？）。
创新：AI 记住你的偏好，越用越懂你。
场景：把"瑞幸"纠正到"咖啡"一次 → 以后自动归咖啡；记住常用商家、支付方式、心情标签。
技术：云数据库存用户偏好 → 分类时先查偏好 → 每次纠错即学习，形成数据飞轮。

---

## 6. 组合打法 + 答辩话术
- 一句话定位："一个会说人话、会主动帮你管钱、还会陪你记生活的 AI 财务管家。"
- 答辩逻辑：讲"记账太难坚持"痛点 → 演示"说一句话/拍张照就记账" → 演示"问账 AI 给建议" → 演示"每晚一篇心情日记" → 演示"订阅到期主动提醒" → 收尾"越用越懂你、越用越离不开"。
- 两个比赛分别强调：
  - FinTechathon：强调 Agent"意图理解、规划、执行"技术深度 + 安全二次确认 + 情感洞察的助手型边界
  - 小程序大赛：强调实用性 + 体验感 + 心情日记带来的粘性与完整度
